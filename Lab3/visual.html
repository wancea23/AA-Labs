Section 04
Conclusion

⏱ Time Complexity

Both DFS and BFS operate in O(V + E) time. BFS is consistently ~30–50% faster in practice, particularly on dense graphs, due to better cache locality of queue-based access patterns.

🧠 Memory Behaviour

DFS memory (stack depth) grows with graph depth. On dense graphs this explodes — a 1 000-node dense graph triggered 248k stack entries vs BFS's 989 queue entries. BFS favours wide/shallow graphs.

🌲 Binary Trees

DFS is ideal for tree-like graphs: stack depth = O(log V) while BFS queue grows to O(V/2) at the widest level. DFS uses 5–6× less memory on binary trees.

🔗 Dense Graphs

BFS dominates on dense graphs — both in speed and memory. DFS stack blows up to O(E) on dense inputs, making it impractical without recursion-limit safeguards.

📏 Scalability

Both algorithms scale linearly with input size, confirming O(V+E). Dense Random graphs reveal the starkest divergence: DFS is 35× slower than BFS at N=1 000.

✅ Completeness

Both algorithms visited all reachable nodes in every test run, confirming their correctness across all three graph topologies and all sizes tested.
